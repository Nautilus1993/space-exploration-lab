# space-exploration-lab

🚀 **中国科学院空间应用工程与技术中心 - 数智技术中心**

## 📖 项目介绍

这是 space-exploration-lab 的单页官网，展示数智技术中心的基本信息、研究方向、导师团队、实验室照片展示与招生计划。

## ✨ 特色

- 🎨 现代化响应式设计
- 📱 支持移动端访问
- 🖼️ 导师照片展示
- ⚡ 纯HTML实现，无需服务器
- 🌟 精美的动画效果

## 🔬 研究方向

- 深空环境感知与预测
- 空间广域可达自主智能飞行技术  
- 分布式多智能体协同导航与自主决策
- 航天器GNSS及多源观测融合相对导航
- AI4空间科学前瞻性研究
- 月球及深空可持续探索技术
